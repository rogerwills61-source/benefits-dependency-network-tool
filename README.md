# Benefits Dependency Network (BDN) Tool

A specialized, keyboard-first web application designed to map and document Benefits Dependency Networks with strict methodological alignment across investment tiers.

## Core Architectural Layers
1. **Enabling Changes (Deliverables):** IT systems, process updates, and physical assets being deployed.
2. **Business Changes (New Capabilities):** How operational behaviors and routines shift once deliverables go live.
3. **Outcomes (Intermediate & Final):** Direct, measurable operational or strategic results.
4. **Strategic Objectives (Drivers):** The overarching corporate goals satisfied by the outcomes.

## Tech Stack
- Single-file PWA architecture (`index.html`)
- HTML5 Canvas 60 FPS viewport rendering
- Local persistence via IndexedDB & GitHub Pages deployment
